# Plot Sketches

All sketches for the IDP Final Project are stored here as PNG images. Each sketch uses mock/placeholder data to illustrate the intended visualization type, axis labels, annotations, and narrative for the corresponding research question.

## Sketch Table

| # | Sketch Image | Plot Type | Research Question | Description |
|---|---|---|---|---|
| 1 | [rq1a_teammate_quali_delta.png](rq1a_teammate_quali_delta.png) | Swarm Plot | **RQ1** — Driver Skill vs. Car | Qualifying deltas between teammates (same car) isolate driver skill; large consistent gaps = skill factor, tight clusters = car dominance |
| 2 | [rq1b_throttle_brake_kde.png](rq1b_throttle_brake_kde.png) | Bivariate KDE | **RQ1** — Driver Skill vs. Car | Throttle-vs-brake input patterns comparing race winner to top 10; trail-braking zone highlights skill-driven racecraft |
| 3 | [rq2a_points_heatmap.png](rq2a_points_heatmap.png) | Heatmap | **RQ2** — Cost Cap Impact on Results | Points concentration per finishing position per year; shows whether heat "bleeds" from P1–P3 to midfield post-2021 |
| 4 | [rq2b_gap_to_winner_violin.png](rq2b_gap_to_winner_violin.png) | Split Violin | **RQ2** — Cost Cap Impact on Results | Time gap distributions to race winner, split by pre/post cost cap era; shorter post-cap violins = field compression |
| 5 | [rq3a_field_spread_ridge.png](rq3a_field_spread_ridge.png) | Ridge / Joy Plot | **RQ3** — Did the Cost Cap Function as Intended? | Lap time delta distributions per year; tail "tucking in" from 2019→2025 shows slower cars closing the gap |
| 6 | [rq3b_performance_tiers_step.png](rq3b_performance_tiers_step.png) | Step Line Plot | **RQ3** — Did the Cost Cap Function as Intended? | Top 3 vs. bottom 3 teams' average gap to pole %; converging lines quantify performance tier compression |
| 7 | [rq4a_wdc_radar.png](rq4a_wdc_radar.png) | Radar Chart | **RQ4** — WDC Predictability (Skill vs. Car vs. Other) | Feature importance profile for 2024 vs. 2025 champion; polygon shape reveals whether car pace or human factors drove the title |
| 8 | [rq4b_standings_confusion_matrix.png](rq4b_standings_confusion_matrix.png) | Confusion Matrix | **RQ4** — WDC Predictability (Skill vs. Car vs. Other) | Car-pace model predicted vs. actual championship rank; diagonal strength = car-predictable, off-diagonal = human factors overriding |

## Plot Type Diversity

The 8 sketches use **6 distinct plot types**: Swarm Plot, Bivariate KDE, Heatmap, Split Violin, Ridge Plot, Step Line Plot, Radar Chart, and Confusion Matrix Heatmap — exceeding the 4+ types recommended in the rubric.
