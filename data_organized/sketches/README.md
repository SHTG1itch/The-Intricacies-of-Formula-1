# Plot Sketches

These sketches were used to plan the final visualizations before the report
plots were coded. They map directly to the research questions and use several
different chart types, which matches the data organization rubric.

| Sketch | Research Question | Why it belongs in the project |
|---|---|---|
| [Teammate qualifying delta](rq1a_teammate_quali_delta.png) | RQ1 | Compares drivers in the same car to isolate driver skill from car pace. |
| [Throttle/brake KDE](rq1b_throttle_brake_kde.png) | RQ1 | Uses telemetry behavior to explain where driver differences come from. |
| [Points heatmap](rq2a_points_heatmap.png) | RQ2 | Shows whether points became less concentrated after the cost cap era began. |
| [Gap to winner violin](rq2b_gap_to_winner_violin.png) | RQ2 | Compares race-time gaps before and after the cap. |
| [Field spread ridge](rq2.1a_field_spread_ridge.png) | RQ2.1 | Shows whether the full field became closer in lap pace over time. |
| [Performance tiers step line](rq2.1b_performance_tiers_step.png) | RQ2.1 | Tracks the top-team versus bottom-team pace gap by season. |
| [WDC radar profile](rq3a_wdc_radar.png) | RQ4 | Summarizes the feature profile of championship-level performance. |
| [Standings confusion matrix](rq3b_standings_confusion_matrix.png) | RQ4 | Shows whether model errors stay close to the correct finishing rank. |
